MarineSense Engine Room Watch Log — Reviewer guide

Spirit class · review version · thank you for testing!

This app replaces the monthly Excel watch / sounding workbook. It runs only on this PC, works without internet, and opens in your web browser. Please try it during normal watches and note anything that is wrong, missing or awkward.

1. Start

  • Start menu → MarineSense Watch Log. A black window opens (keep it open; closing it stops the app) and the browser opens http://127.0.0.1:5080/.
  • If Windows shows “Windows protected your PC” during installation: click More info → Run anyway (the review version is not code-signed yet).
  • Your entries are stored on this PC in %LOCALAPPDATA%\MarineSense\WatchLog. They are never sent anywhere.

2. Practise first in Training mode (recommended)

Start menu → Watch Log – Training (sample data). It opens a separate copy at http://127.0.0.1:5081/ with 14 days of invented readings and a yellow TRAINING MODE banner. Try anything there — nothing touches the real log.

3. Try a real watch

  1. Settings: set the vessel name; under Opening balances enter the counter readings from just before your first watch; mark fields your ship does not use as Not in use.
  2. Watch board: choose the ship date, then Start watch.
  3. Type readings. Enter = next field, Shift+Enter = back, Ctrl+J = jump to a section. Each value saves automatically. Use ⋯ to mark a reading unavailable with a reason.
  4. Review & close: choose the officer, check the closure time, close. A PDF is created — open it from the record page.
  5. Look at History and Reports (compressor hours per watch, day, week, month).

4. Give feedback — the most important part

On any screen, press the yellow ✎ Feedback button (bottom-left). Write what you think — the app remembers which screen you were on.

Useful things to tell us:

  • Equipment, tanks or readings that are missing or named differently on your ship
  • Units for M4.1–M4.3, GS, LT/HT and DG sump LOC/DAM (marked “unit unconfirmed”)
  • The real rollover value of each counter (when does it go back to zero?)
  • Steps that are slow or confusing, and things that work well
  • Anything the Excel sheet does that this app does not

When finished: menu Feedback → Export notes. A text file is saved in Downloads — send it by email or WhatsApp. It contains only your notes, name, app and Windows version — no watch readings.
